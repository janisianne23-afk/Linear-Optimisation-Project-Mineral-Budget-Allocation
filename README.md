# Linear-Optimisation-Project-Mineral-Budget-Allocation
This project involves data cleaning and analysis to optimize budget allocation for Gold and Iron Ore based on historical expenditure and commodity prices. Using Pandas and SciPy, the results show that Gold has a stronger correlation score, receiving the majority budget allocation to maximise overall return.

## Methods
* **Python Libraries: ** 'pandas', 'scipy.optimize', 'matplotlib'
* **Mathematical concepts:** Correlation analysis, linear optimization, and data normalization

## How to run the project
1. Open and run 'Project3_CLEANING.ipynb' to process raw dataset and generate standardized data.
2. Open and run 'Project3_Analysis.ipynb' to view the statistical correlations, graphs, and final optimization results.

## Key findings
* Gold demonstrated a significantly stronger correlation to positive returns compared to Iron Ore.
* **Conclusion:** The optimal allocation strategy prioritizes Gold over Iron Ore to maximize overall returns.
